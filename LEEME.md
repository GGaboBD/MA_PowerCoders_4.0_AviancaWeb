# Avianca — concepto premium

Primera maqueta de escritorio de un proyecto universitario, enfocada en viajeros de clase ejecutiva y primera clase. No es un sitio oficial de Avianca.

## Abrir y editar

Abre `dist/index.html` directamente en el navegador. No requiere instalación, servidor ni conexión para mostrar sus recursos locales. También puedes abrir la carpeta `dist` en Visual Studio Code y utilizar Live Server.

- `dist/index.html`: estructura y textos del index.
- `dist/style.css`: estilos propios, divididos y comentados por sección.
- `dist/assets/`: fotografías conceptuales generadas y fuente local.

La navegación lleva a secciones del mismo index. El buscador es una maqueta estática y el botón está deshabilitado: no busca ni vende vuelos. No hay JavaScript, pagos, cuentas, seguimiento ni peticiones a servicios de Avianca.

## Dirección visual

Del archivo DESIGN.md y Hyer: titulares grandes, composición asimétrica, mucho espacio, botones ovalados, divisores finos y tarjetas sin sombras.

De los archivos aportados de Avianca: Red Hat Display, blanco y el negro `#131313`. El rojo `#da291c` es una elección para este prototipo, no un token verificado del CSS adjunto.

El logotipo se representa mediante texto estilizado. Las imágenes generadas muestran un avión y una cabina imaginarios: no son fotografías de la flota ni de un producto de Avianca. La sección de primera clase es una propuesta académica, no una afirmación sobre servicios disponibles. No se incluyen precios, rutas ni prestaciones garantizadas.

## Alcance

Diseñado para pantallas de computadora desde 1100 px de ancho. Se pospone deliberadamente la adaptación móvil y el desarrollo de las demás páginas. Los estilos usan variables para facilitar los siguientes cambios.
